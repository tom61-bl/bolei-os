# BOLEI.OS — 博磊的个人作品集

> 极客黑客风单页作品集：一个开机自检、命令导航的个人操作系统。

- 在线访问：https://tom61-bl.github.io/bolei-os/
- 仓库：https://github.com/tom61-bl/bolei-os

## 板块

| 命令 | 板块 |
| --- | --- |
| `whoami` | 我是谁 |
| `ps aux` | 现在在做什么 |
| `cat interests.conf` | 兴趣与想链接的人 |
| `cat roadmap.md` | 创作方向 |
| `ls -la ~/projects` | 作品集 |

## 技术栈

单文件 HTML + CSS + 原生 JS，无构建、无依赖。JetBrains Mono 等宽字体。

## 文件

- `index.html` — 作品集主页面
- `jd-tailor-prep.md` — 求职方法论 Skill（JD 定制与面试准备 10 步流程）
